# SMS and Email Spam Detection

## Machine Learning
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Spam and Ham Classification
- Trigger Word Identification

## Model Performance
- Accuracy: 93.59%
- Precision: 93.72%
- Recall: 93.59%
- F1 Score: 93.61%

      How It Works

      1. 1

        Enter a message

        Paste or type the SMS you want to check.

      2. 2

        AI analyses it

        The Flask server turns the text into features and the model scores it.

      3. 3

        See the result

        You get a Spam or Not Spam label and the words that influenced it.

      TF-IDF

      Converts text into numerical features based on how important each word is.

      Multinomial Naive Bayes

      Classifies messages as spam or ham using word frequencies.

      Flask

      Handles the API request and returns the prediction as JSON.

      About This Project

      GUARDIX is an educational AI & ML project. It shows how a machine learning model can learn patterns in text messages to separate spam from legitimate (ham) messages.

      No model is perfect. Results may be wrong, so treat them as guidance and not as guaranteed security. Never share passwords, OTPs or card details because of a message.

      A college AI & ML project that classifies SMS messages using machine learning.
